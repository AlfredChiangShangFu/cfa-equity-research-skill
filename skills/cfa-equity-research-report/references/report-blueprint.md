# 固定報告版型

## 目錄

1. 標題與整體格式
2. 執行摘要
3. 公司、商業模式與策略定位
4. 市場規模與競爭格局
5. 財務品質、單位經濟與客戶指標
6. 風險、監管與 ESG
7. 估值、情境與敏感度
8. 投資論點、催化劑與最終建議
9. 交付檢查表

## 標題與整體格式

使用下列 H1：

```markdown
# {法定公司名}（{交易所}: {Ticker}）CFA 等級投資研究報告
```

接著只使用下列七個 H2，名稱與順序固定。以粗體主題句建立章內層次；非必要時不要再切很多 H3。報告應像已完成的 sell-side／buy-side initiation note，而不是填空問卷。

所有表格遵守三個原則：

- 最新期間與 Base 情境加粗。
- 表格下方立即註明資料來源、期間、幣別、單位、公式與推算限制。
- 沒有可靠資料時寫 `未揭露`、`N/A` 或 `N/M`，不要猜測或刪掉限制。

## 執行摘要

使用標題：

```markdown
## 執行摘要
```

第一句必須加粗，並一次列出：

- 研究基準日
- 最終評級與方向，例如 `BUY／Outperform`、`HOLD／Neutral`、`SELL／Underperform`
- 同一基準日現價
- 12 個月 Base 目標價
- 36 個月 Base 目標價

接著依序寫三段：

1. 公司定位與最新營運訊號：最新營收、成長、指引及最重要的產業 KPI。
2. 股票問題或機會：現價隱含預期、相對估值與市場可能定錯價之處。
3. 主模型結論：Base 的主要假設、每股價值、Bull／Bear 差距及評級核心理由。

加入「投資快照」二欄表。至少涵蓋下列經濟等價項目：

| 投資快照 | 判斷 |
|---|---:|
| 現價與市值 |  |
| 最新營收／成長 |  |
| 最新全年指引或外部預估 |  |
| 產業核心 KPI |  |
| 毛利率／營業利益率／現金流率 |  |
| 現金、債務與淨現金／淨負債 |  |
| Bear／Base／Bull 每股價值 |  |
| 12 個月 Base 目標價與上／下行 |  |
| 36 個月 Base 目標價與上／下行 |  |
| 最終評級 |  |

表後用一段明確區分「公司品質」與「以目前價格買入後的風險調整報酬」。

## 公司、商業模式與策略定位

使用標題：

```markdown
## 公司、商業模式與策略定位
```

依序處理：

- 法定分部、產品／服務、客戶、地理、通路與未揭露範圍。
- 收入來源、合約長度、價格機制、經常性／用量型／交易型收入、循環性及現金轉換。
- 收入引擎表：`收入引擎｜收費機制｜投資含義`。
- 護城河與反護城河：規模、網路效應、轉換成本、品牌、資料、成本、監管資格及其可被破壞的方式。
- 成長向量與資本密集度：成長是否需要更多銷售費用、庫存、廠房、GPU、研發或併購。
- 管理層策略、重大產品、重組、併購與資本配置；把已發生事實和管理層企圖分開。

若關係複雜且能提升理解，可加入一個 Mermaid 商業模式 flowchart 或策略 timeline。不要為裝飾而畫圖。

## 市場規模與競爭格局

使用標題：

```markdown
## 市場規模與競爭格局
```

必須包含：

- TAM／SAM／市場成長的來源身分。管理層估計必須直接標示，不得包裝成獨立統計或精確市占。
- 3–6 家最接近同業的競爭矩陣；使用同一或最近可比期間與同口徑指標。
- 各公司的核心定位、成長、規模、毛利／報酬、核心能力、結構優勢與弱點。
- 同業定義不一致、私有競爭者或分部未單獨揭露的限制。
- 地理、產品、客戶或終端市場組合；選擇公司實際有揭露且最能解釋風險的一種。
- 產業議價權、替代品、進入障礙與景氣／法規驅動因子。

競爭矩陣至少使用：

| 面向 | 標的公司 | 同業 A | 同業 B | 同業 C |
|---|---|---|---|---|
| 核心定位 |  |  |  |  |
| 同期間成長與規模 |  |  |  |  |
| 核心產品／能力 |  |  |  |  |
| 獲利／資本效率 |  |  |  |  |
| 結構優勢 |  |  |  |  |
| 結構弱點 |  |  |  |  |

## 財務品質、單位經濟與客戶指標

使用標題：

```markdown
## 財務品質、單位經濟與客戶指標
```

先用一段話說明多年成長、獲利與現金轉換的方向，再放表格。

### 必備資料

- 在資料可得時提供至少 5 個完整年度的營收、成長、毛利／毛利率、營業利益／率、淨利、OCF、資本支出、FCF 與 FCF margin。
- 提供最近 5 季的營收、成長、毛利／率、營業利益率與現金流指標。年度減前三季得到的季度、一次性費用或重編數字要直接標示。
- 提供資產負債表品質：現金、投資、債務、租賃、淨現金／淨負債、流動性與到期結構。
- 提供每股品質：SBC、股份數、回購、可轉債與完全稀釋股數變化。
- 提供 3–8 個真正驅動該產業的單位經濟／客戶 KPI；例如 NRR、ARR、訂閱戶、同店銷售、出貨量、ASP、利用率、良率、存款、NIM、combined ratio 或 AFFO。
- 提供 visibility 指標，例如 backlog、RPO、book-to-bill、deferred revenue、訂單、預售、存款或租約到期。

不要把代理指標冒充公司正式 KPI。例如 `S&M／新增客戶` 只能稱 sales-efficiency proxy，不能稱 CAC。若公司停止揭露 KPI，要說明透明度與可比性下降。

## 風險、監管與 ESG

使用標題：

```markdown
## 風險、監管與 ESG
```

先用至少三個因果段落說明最重要的基本面風險：風險如何發生、會影響哪個財務驅動、目前有何證據、如何監測。至少覆蓋估值、營運／執行與資本／財務之一。

加入風險矩陣：

| 風險 | 機率 | 衝擊 | 關鍵監測指標 |
|---|---|---|---|
|  |  |  |  |

另行處理：

- 具財務重要性的產業監管、訴訟、資料／產品安全與地緣政治。
- 利率、匯率、原物料、企業支出、消費或信用循環等宏觀敏感度。
- E／S／G 各自最具財務重要性的證據與反證。不得把公司永續宣傳直接等同低風險；無重大性時簡短說明即可。

## 估值、情境與敏感度

使用標題：

```markdown
## 估值、情境與敏感度
```

先重建基準日估值橋接：

- 現價 × 適當股數 = 市值。
- 市值 + 債務 + 特別股 + 少數股權 − 可扣除現金／投資 = 企業價值。
- 列出 TTM 與至少一個 forward multiple，並揭露財務期間、幣別、股數與資料來源。

依序提供：

1. 相對估值表：標的與同業使用相同分母與期間，並解釋 premium／discount 是否由成長、利潤率、資本效率或風險支撐。
2. 主估值法的 Bear／Base／Bull 假設表。
3. Bear／Base／Bull 估值輸出表，至少含企業／股權價值、稀釋股數與每股價值。
4. 兩個最重要變數的敏感度矩陣或等價壓力測試。
5. Reverse DCF／Reverse DDM／Reverse multiple：反推目前價格所需的成長、利潤率、ROE、商品價格或倍數；清楚標示為市場隱含要求而非預測。
6. 重大先例交易。只有可由可靠來源建立可比財務分母時才計算交易倍數，否則寫 `N/M`，避免 false precision。
7. 12／36 個月 Bear／Base／Bull 目標價表。說明各期收入／獲利／帳面價值、目標倍數、淨負債與稀釋股數。

目標價表使用下列形式：

| 情境 | 12M 估值框架 | 12M 目標價 | 36M 估值框架 | 36M 目標價 |
|---|---|---:|---|---:|
| Bear |  |  |  |  |
| **Base** |  |  |  |  |
| Bull |  |  |  |  |

DCF 不一定是所有產業的主方法，但必須保留估值紀律。金融、REIT、礦業或尚未形成正常化現金流的公司，依研究標準使用更合理的方法並說明。

## 投資論點、催化劑與最終建議

使用標題：

```markdown
## 投資論點、催化劑與最終建議
```

先以最強版本呈現 bull thesis 與選擇權，再回答「有多少成功已反映在目前價格」。加入：

| 核心投資論點 | 支持證據 | 對股票的解讀 |
|---|---|---|
|  |  | 正面／負面／雙面 |

接著依序寫：

- 未來 12 個月正面催化劑及可觀測門檻。
- 負面催化劑與預期正常化風險；說明公司仍表現不錯時，股票為何仍可能下跌。
- 2–5 個 thesis falsifiers：哪個數字、事件或估值變化會迫使改評級。
- 稀釋、資本配置或負債對每股報酬的影響。
- 粗體最終評級、12 個月與 36 個月 Base 目標價。
- 一句話 blockquote，濃縮公司品質、價格與風險報酬的矛盾。
- 最後分開陳述 business quality 與 stock valuation，並以兩者如何導出評級收尾。

## 交付檢查表

- 七個 H2 都存在且順序正確。
- 執行摘要已在第一段給日期、評級、現價與 12／36 個月目標價。
- 至少有投資快照、收入／商業模式、同業、歷史財務、近季、KPI、風險、相對估值、情境、目標價與論點等經濟等價表格。
- 每個重要表格緊接資料來源或計算註記。
- 已報告實績、管理層指引、外部預估、分析師假設、本研究計算與推論皆可區分。
- 估值方法符合產業；股數、淨負債、SBC 與稀釋沒有遺漏。
- 目標價上／下行與評級一致；Bull 與 Bear 都是可辯護情境。
- 沒有某一特定公司的專屬欄位、數值、產品名或失效圖檔被硬編到其他公司。
- 沒有空白佔位符、內部引用 ID、失效 sandbox 連結或無來源的精確數字。
- 結論清楚回答好公司、好股票與推翻條件。
