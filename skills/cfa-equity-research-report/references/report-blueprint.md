# 固定八章報告版型

H1 寫 `# {法定公司名}（{交易所}: {Ticker}）CFA 等級投資研究報告`，之後只用下列八個 H2，名稱與順序固定。範例是封版的 2454 報告 `ib-equity-research` skill 的 `reference-2454/`（MD、config.json、charts.json），對照時用 `grep -n` 抽段落，不整份讀。

## 全篇寫法

**MD 與 HTML 的分工。** MD 是完整研究，深度只增不減；HTML 是本人閱讀版，從 MD 挑選。不想在 HTML 出現的內容包 `<!-- html:skip -->`，不刪除；查數字用的完整報表、參數明細與驗證性表格包 `<!-- html:appendix -->` 進文末附錄（正文留一行連結，或用 `quiet` 把連結寫進段落）；正反並列的清單包 `<!-- html:cols -->`（欄間 `<!-- html:col -->`）成雙欄。標記語法與 config 欄位見 `ib-equity-research` 的 BUILD.md，圖寫 `charts.json`（研究 repo `docs/研究輸出格式.md` 第七節，八種必有圖缺一不可）。揭露限制集中在隱藏區，正文只在影響判斷時提一次；版本對照與跨 AI 對照不進 HTML。

**段落與小標。**
- HTML 可見的每一段第一句是粗體判斷句，後接一到兩句佐證；不用名詞標籤段首（「每股品質。」），不用「三點解讀」式條列；精確推導與完整數字放表格、附錄或隱藏區。同一節的段首標籤同類（風險章一律「X 風險：」），補充內容寫進所屬段落。
- 小標＝主題名詞＋冒號＋結論（「資產負債：存貨年增 77%」），不用口語問句；小標與欄首不加括號補充。最關鍵的解釋上小標，未證實的保留「可能」。小標寫「優勢」時只能放優勢；優劣並陳用「競爭地位」，段首標明優勢或弱點。一節只剩附錄連結就不設小標，連結寫進段落。
- 數字有升降就接「主因」，證據不足標推論；寫到轉折（轉負、反轉）同一句交代原因與金額；變化明顯時查財報附註的組成拆解（存貨、應收、合約負債），推論與公司說法分開標。只有百分比處補金額。
- 半欄圖旁的文字要描述該圖本身；側欄小表與左欄不等高時改段落順序或補讀圖數字，不縮字。
- 交叉引用寫「附錄 A3」「Exhibit 12」「第 4 章」或用「」括住小標全名，自動成頁內連結。

**用語。** 專業金融口吻。禁翻譯腔（「提供上行」）、AI 句式（「這張表的重點」）、內部流程用語（issue 編號、版本代號、檔案路徑）。產業慣用英文縮寫（ASIC、CSP）直接用；冷門縮寫與專有名詞（SBC、NRE）首次寫中文全名或一句白話；估值方法名稱首次附英文（Forward P/E Multiple、Reverse Valuation），其餘英文夾雜改中文；公司自稱的口徑名稱保留原詞。客戶寫品牌名與占比（附來源與時點）；產品寫型號與代號，不寫「首款」「第二款」；「第 N 個專案」要寫前幾個是什麼、這個是誰、哪年。公司未證實的客戶、型號一律推測並標依據與可信度；匿名客戶用對手方揭露交叉比對猜是誰。

**表格與圖。** 每張表後接一行來源註（來源名稱、期間、幣別、單位、推算限制），不夾檔案路徑；最新期間與 Base 加粗；沒有資料寫 `未揭露`、`N/A` 或 `N/M`。多期限表的欄名寫期限與到期日，正文引用要說在哪一欄；橋接表用數值正負號，不寫「加：」「減：」；價位表的觸發方向寫進動作欄（漲到／跌到），不另立方向欄；事件日期用台灣日期，不寫地點與時區，上行與下行分行。圖：文字寫「轉負」的期間，圖上要有那一期本身，不能只放平滑後的 TTM；散佈圖有單一極端值設 `y上限`。

## 執行摘要

第一段是 `html:skip` 包住、前後空行的基準行，逐字含「研究基準日 YYYY-MM-DD」「評級」「現價」「12 個月 Base 目標價」「36 個月 Base 目標價」與相較同系統上一版的變動（首次覆蓋寫「首次覆蓋」）；validator 讀這段，HTML 由刊頭與評級條呈現。可見內容依序：

1. 3 到 5 點編號要點，依重要性排序，每點「粗體完整判斷句＋一到兩句佐證」。以訊息面與產品面為主：財報、產品型號、客戶、訂單，講到供應鏈環節與製程；主要風險合成一點；估值最多一點且放最後：目標價、本報告對共識的 EPS 差距與差距來源的關鍵假設、倍數依據，不講方法與門檻，推導留估值章。
2. 投資快照表（Exhibit 1）：`項目｜金額／數值` 兩欄，或全寬雙組四欄；8 到 12 項、每值連同幣別與單位一起寫，放投資人直接要的：市值、本益比、本報告 EPS 對共識、毛利率與營益率、公司指引、關鍵假設、目標本益比、殖利率、下個催化劑。不重複刊頭（目標價、三情境、評級）；來源註只寫來源名稱。
3. 今年以來日 K（`charts.json` 的 `日K`，章節寫執行摘要）全寬，事件標籤講今年的故事。

## 公司、商業模式與策略定位

- 定位段：一句粗體定位（做什麼、賣給誰、資產輕重），後接成立、掛牌、經營團隊與股數。
- 營收結構：分段寫各產品群占比、成長與主因（產品、地理或客戶組合擇最能解釋風險的一種）；單一期間占比用 `組成` 圓餅圖不用表，加 config.chartNotes 註記（各群產品、客戶與金額）成「圖｜註記」一列。
- 事業別表（全寬）：`事業｜主要產品｜終端客戶｜商業模式｜近況`，每格白話短句（「賣晶片給手機品牌，逐案議價，沒有長約」）。
- 商業模式圖：mermaid flowchart，欄例如「能力與供應鏈｜產品線｜客戶與下一步」，只畫因果或價值鏈。
- 最大成長引擎獨立專節：客戶是誰（公司未點名時寫市場共識並標未證實）、技術分工、規模與指引、世代路線表（款名、量產時點、製程或規格、公司角色）、```timeline 時程軸（證實與報導分開）、與關鍵供應商的產能連結。供應鏈段範本：粗體講瓶頸與對策，佐證依序產能占用、公司證實、賣方第二來源，末句收到對營收的影響。
- 資本配置：側欄小表（月份｜動作｜金額）＋粗體結論段（籌資目的、策略投資、股利）。
- 本章只講公司做什麼：競爭優勢放市場章，劣勢歸風險章，不用「護城河」「反護城河」。

## 市場規模與競爭格局

- 終端市場每個一節，小標點明市場與公司位置。開頭先講買家是誰、份額怎麼分（含傳聞中的新客戶，標可信度），不先講統計口徑。市場規模選定一個口徑，採用理由寫在表的來源註，各機構估計縮成側欄小表，正文講 CAGR 與公司可拿份額，配 `柱線` 成長圖。終端市場段範本：粗體講市場規模變化與公司位置，佐證依序兩家獨立機構數字、管理層說法、衰退原因、市占對照（附來源與日期），末句註明口徑限制。
- 下一代產品時程：時程軸或表，點出機會窗口。
- 近期消息：小標點出利多與利空的來源性質（例如外資傳聞對公司公告）；事件時程軸；有利與不利清單雙欄，每條末尾標來源與可信度。
- 競爭地位：優勢只放真正的優勢（進入障礙），弱點標明（議價權、產能）；數字來自附錄的競爭矩陣（3 到 6 家同業、同期間同口徑、公司揭露的限制）。估值比較只放估值章。

## 財務品質、單位經濟與客戶指標

- 章首一段粗體：五年營收區間與轉折次數、毛利率區間、營益率起訖與原因、自由現金流區間與最近轉折及原因。
- 正文每節「小標結論＋一到三段」，配 `營收利益率`、`現金流`、月營收等半欄圖，文字描述該圖的數字。完整報表全部進附錄：年度損益（至少 5 年，含 OCF、資本支出與 FCF）、近五季、產業 KPI（照 [產業模板](industry/README.md)，`appendix quiet`）、資產負債品質（現金、債務、租賃、淨現金）。
- 每股品質（SBC、股數、可轉債、完全稀釋）與能見度指標（backlog、月營收）各一段，段首是判斷句；停止揭露的 KPI 要說明。

## 風險、監管與 ESG

- 風險總覽：`風險矩陣` 熱圖半欄放章首，格內寫「X 風險」；旁邊兩段：小標結論（哪項衝擊最大、哪項機率最高）與分類對照；追蹤指標表進附錄。
- 主要風險每項一段，段首「X 風險：」粗體判斷句，與熱圖同名，名稱要單看就懂（一項含兩件事就兩件都寫）；講成因、影響哪個財務驅動、證據、追蹤指標，至少覆蓋估值、營運、資本之一；客戶集中要推測匿名客戶是誰並補金額。
- 監管與宏觀：側欄小表（規則或變數｜狀態），解讀寫進並排正文，推論處標明；匯率與利率敏感度補金額。
- ESG 一段為上限：粗體講有無重大負面事件與具財務重要性的項目，後接 E、S、G 各一到兩個數字與來源；不把永續宣傳當成低風險。

## 估值、情境與敏感度

正文只放決定目標價的算式與每個乘數的來源，依序：

1. 估值方法：這檔適合哪種方法、為什麼（獲利階段、資產輕重）、哪些只當交叉檢查、哪些不用（standards 原則二）。
2. 目標價：段首粗體給算式（「12 個月 3,800 元 = 未來一年 EPS 189.2 元 × 20 倍」），接 ``` 算式框，再一段講 EPS 與倍數各自的出處；三情境目標價表 `情境（機率）｜12 個月目標價（到期日）｜36 個月目標價（到期日）`，算法寫格內括號，機率加權列加粗；`估值區間` 圖只畫三情境與機率加權。
3. EPS 怎麼來：Bear／Base／Bull 三點，每點「粗體經濟敘事＋關鍵假設、EPS、目標價與倍數」，接假設明細表（經濟敘事列每格約 10 字）與三情境盈餘對共識表。
4. 歷史估值（Historical Valuation）與相對估值（Relative Valuation）各一節，小標講倍數出處；倍數表改側欄小表、同業表精簡並與散佈圖並排，`倍數河流` 掛歷史估值節，口徑寫進正文。
5. 和現價比：BUY／HOLD／SELL 價位區間；Reverse Valuation 留一句結論連到附錄。
6. 交叉檢查：DCF、SOTP、共識乘倍數一表；先例交易有可比分母才列，否則寫 `N/M`。

附錄（`appendix quiet`）：估值橋接（市值到企業價值，含稀釋股數與淨負債）、DCF 參數與三情境 DCF 每股、兩張敏感度、Reverse Valuation 逐項（標市場隱含要求）；`敏感度` 與 `反向估值` 兩張圖仍寫進 charts.json 並標 `隱藏`。

## 籌碼與交易計畫

依 [籌碼與事件交易標準](positioning-and-trade-plan.md)。籌碼表與價量表進附錄，正文留結論段與半欄圖並補讀圖數字；事件一節用「催化劑」一詞，表精簡成 `日期｜事件｜驗證什麼｜上行／下行｜行動｜來源`；交易決策表；操作階梯 `層級｜觸發價｜執行後持倉｜動作｜理由`。末句交代對最終建議的作用。

## 投資論點、催化劑與最終建議

- 投資論點：粗體先講多方最強版本與已反映多少；論點表 `核心投資論點｜支持證據｜股價影響`。
- 催化劑：正負各列可觀測門檻，只提影響評級的事件；預期正常化風險一段（公司表現好股票仍可能跌）。
- 推翻條件：2 到 5 條編號，每條「粗體可觀測條件＋觸發後怎麼改評級或模型」。
- 最終評級句：粗體寫評級、12／36 個月 Base 目標價、Base 與機率加權的 12 個月預期總報酬；一句 blockquote；公司品質與股票估值分開收尾並導出評級，籌碼與事件如何影響現階段行動；末段列未取得的資料。

## 交付檢查表

- 八個 H2 齊全且順序正確；基準行是執行摘要第一段且用字逐字照規定；各章必備表格齊全並緊接來源註，該進附錄或側欄的已標記。
- 證據標籤可區分；股數、淨負債、SBC 與稀釋沒有遺漏；目標價與評級一致；沒有其他公司殘留、佔位符、內部引用、失效連結、無來源的精確數字與流程用語。
- 結論清楚回答好公司、好股票、現階段行動與推翻條件。
