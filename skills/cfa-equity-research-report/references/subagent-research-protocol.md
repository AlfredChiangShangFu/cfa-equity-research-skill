# 代理協定：主代理保留研究判斷

## 平台與模型

- 模型分工見 SKILL.md。以工具當次公布的可用模型與參數為準，Claude 不照搬 Codex 的 model／effort 欄位；固定模型的自訂代理遵守其設定，不宣稱用了別的模型。模型不同時用不繼承整段歷史的派工方式，給最小充分背景。
- skill 不會切換正在執行的主模型；只有宿主支援且使用者授權時切換，不改全域預設。
- 指定模型不可用時不得假裝已使用；說明後採當下可用的輕量模型，或由主代理完成小任務。沒有代理工具時直接執行，品質門檻不變。

## 先共用取數，再依缺口分工

預設委派。主代理先整理已取得資料及缺口，代理數依缺口決定，不固定四線、不設 token 門檻；每個數據集只有一個取得責任者，其他代理讀共用原始回應與帳本。

可獨立委派的例子：

| 任務 | 明確輸入與完成條件 |
|---|---|
| 申報抽取 | 指定文件與項目，回傳原值、期間、單位、頁碼／段落、URL |
| 同業取數 | 指定同業與共同口徑，只補共用資料缺欄 |
| 事件核實 | 指定事件與日期範圍，找正式公告並區分已發生／預定 |
| 產業證據 | 指定可檢驗問題，提供獨立來源與相反證據 |
| 視覺檢查 | 指定 HTML 與 delivery 第 4 步項目，逐項回報可見與否及位置，不改檔 |

不委派輕量代理決定 WACC、正常化獲利、會計調整、估值法、情境、反證裁決、目標價或評級。抽取遇到重編、累計／單季、SBC、多股別（取各股別期末在外合計）、可轉債或來源衝突，列出原文交主代理。

派工只含：標的／截點、具體問題、可用資料路徑、准許寫入的輸出路徑、來源約束，以及先讀本 skill 的 [subagent-brief.md](subagent-brief.md)。明確告知不是唯一工作者，不得覆蓋他人輸出。用宿主通知接收回報，不輪詢。

## 主代理驗收

1. 讀精簡回報，按問題抽閱完整帳本；不把所有下載原文重新載入。
2. 核對期間、幣別、股別及各線同一數字；市值用期末在外股數，不能拿 EPS 加權平均股數直接替代。
3. 親自重驗現價／日期、適用稀釋股數、最新季營收、獲利、最新全年指引及淨現金／淨負債；使用原始文件或可追溯資料，對衝突留下裁決理由。
4. 「未查得」不等於「未揭露」；影響結論的缺口補查或標示非決策就緒。引用原始 URL，並保留 ToAlpha 取得路徑，不把代理回報當來源。
5. 只有主代理通過的證據才能進模型。節省取數成本不改變研究與估值的完成門檻。
