# 研究、證據與估值標準

## 研究截點與來源層級

會隨時間變動的事實都要在本次研究中查證。取數入口依 data-sources.md；以下是證據權威與衝突裁決順序。以同一研究基準日為界：

1. 監管申報、交易所資料、公司正式 IR／法說稿、經審計財報。
2. 公司正式產品、定價、交易、治理與法律公告。
3. 同業各自的一級來源；不可用標的公司對競爭者的描述代替。
4. 政府、央行、法院、產業監管者與國際組織。
5. 方法透明的市場資料庫、信用評等、研究機構與高品質媒體。
6. 其他二級來源只補背景，不可單獨支撐關鍵估值輸入。

價格、股數與市值必須帶日期；休市日用最近交易日並明示。share class、ADR 或幣別不清時不要直接使用。

## 證據標籤與引用

證據帳本每項標成：`已報告實績`、`管理層指引`、`外部預估`（有可識別來源）、`分析師假設`、`本研究計算`（可由已列數字與公式重算）、`推論`。

- 描述性連結放在支撐的句子附近；每個表格後放 `資料來源：...；本研究計算。`。
- 不輸出工具內部 reference ID、搜尋結果頁或 sandbox 路徑；不長篇複製原文。
- 重大主張優先用一級來源；二級與一級衝突時以較新的正式文件為準並說明差異。

## 財務重建與可比性

- 統一幣別、單位、財年與季度；自然年與非自然年比較用 LTM 或最接近季度並標記。
- 分開 GAAP／IFRS 與 non-GAAP，不混配。推算季度（`全年 − 前九個月`）標本研究計算並查重分類。
- FCF 寫出定義（常見 `OCF − 購置 PP&E − 資本化軟體`）。EV 橋接 `市值 + 有息負債 + 特別股 + 少數股權 − 可扣除現金與投資`，受限或營運必要現金不全扣。
- 每股價值用完全稀釋股數，處理 RSU、期權、可轉債、回購與 ADR 比率。
- 管理層 TAM 不等於獨立市場統計；NRR、backlog、活躍用戶等定義各家不同要說明；代理指標只能稱 proxy。
- 一次性費用、收購會計、重組、資產處分、租賃與稅務效果要判斷是否影響正常化獲利。

## 估值方法選擇

估值分兩軌。以下五條原則固定，報告不得自訂；方法依公司判斷，附錄只是參考做法，不用時寫理由。

1. **雙軌。** 12M 目標價（市場 12 個月後可能付多少）給評級；內在價值（值多少）只產出偏貴提醒，不得前滾一年當 12M 目標價。
2. **先講估法。** 估值章開頭寫明這檔適合什麼方法、為什麼（商業模式、資產輕重、獲利階段、週期性），以及不用其他方法的理由。重資產與輕資產不混比；找不到可比同業就說明。
3. **預測與評價分開。** 12M 目標價 ＝ 評價（倍數或其他方法）× 12 個月後往前看的營收、獲利或淨值。預測由報告自估，與共識差距超過 10% 寫理由。
4. **倍數不得無故回歸。** Base 倍數從現行倍數出發，任何變動都寫理由，不得無故假設一年內回到歷史或同業平均（一年期估值約 83% 延續）。
5. **評級條件。** 見「目標價與評級」。

**內在價值軌。** 內在價值為 Base DCF 每股價值（金融業可用剩餘收益模型），每年以股東資金成本減殖利率前滾。偏貴提醒價 ＝ 內在價值 × 報告訂的容忍倍數，倍數寫理由。36M 目標價 ＝ 內在價值前滾三年，不用於評級（假設價格三年內向價值收斂，可低於 12M Bear）。報告自訂操作階梯可設賣點（價格只作本版錨定參考），但寫明錨在哪一軌，不得以內在價值觸發賣出。定價軌評級推翻條件不用「12M Base ÷ 門檻」價格線，改用驅動評級的預測變數門檻（如下一前瞻年度營收成長）。

**分析師共識。** 只取 ToAlpha：美股 `analyst_consensus`；台股 `estimates`（共識 EPS ＝ 上一年度實際 EPS × 共識成長率）與 `estimate_revisions`（direction=down、window_days=90、year=next、limit=50；筆數小於 limit 即清單完整，不在清單內視為未下修）。只用於原則三的預測對照與原則五的下修判斷；券商目標價只列對照。分析師少於 3 位不採用修正訊號。共識未涵蓋 NTM 大半（FY+2）時標「無可比共識」。引用寫取得日期與分析師人數。

### DCF 紀律

- 列出預測期收入、margin、稅率、再投資、營運資金、WACC／COE、終端成長與股數。終端成長高於名目經濟增長、終端 margin 與競爭及資本需求不一致時都要解釋。
- 揭露 terminal value 占比；過高時加重敏感度與 Reverse DCF。
- 口徑配對：WACC 只配 FCFF，得企業價值再扣淨負債；COE 只配 FCFE，不再扣淨負債。SBC 只罰一次：FCF 已扣 SBC 就不再另計稀釋。買回能力用報導 FCF 減股利。

### 相對估值紀律

- 倍數以 forward（NTM 或下一完整財年）為主，TTM 只作補充並標示；無可追溯 forward 共識，或分母不可靠（私有公司、未拆分分部、交易先例）時寫 `N/M`；口徑跨報告固定。
- 同一張表用同一幣別邏輯與分母定義。premium／discount 要連到成長、margin、資本效率、資產負債表、治理或風險。

## 情境、Reverse Valuation 與評級

### 主代理的財經推理審閱

找出最影響每股價值的經營變數，說明「證據 → 收入／成本 → 再投資／現金流 → 股數與價值」的因果鏈。分開管理層指引、市場共識與自己的假設；檢查成長與資本需求、終值與競爭、稀釋與資本配置是否一致；用最強反方證據挑戰 Base。每個核心論點須有可觀測的推翻條件。

### Bear／Base／Bull

每個情境是完整的經濟故事。Bear：較弱需求或市占、較低 margin、較高資本需求或折現率、更高稀釋。Base：最可能且有證據的路徑，不照抄指引。Bull：強執行與有利產業條件，仍受產能、競爭、資本與宏觀約束。

### Reverse Valuation

反推目前價值要求的 CAGR、終端 margin、ROE、商品價格、cap rate 或維持倍數，標成「市場隱含要求」並與預測分開，再與歷史、管理層目標、同業與市場規模比較。

### 目標價與評級

以 12M Base 總報酬給評級，門檻固定：BUY ≥ +15%；HOLD 介於 −10% 與 +15%；SELL ≤ −10%。SELL 另需下列之一，否則降為 HOLD 並標「偏貴」：下一年度 EPS 共識 90 天下修 3% 以上；有日期的下修事件（如下修指引）。Base 隱含漲幅超過 +30% 必標「低信心」，依據薄弱亦可標，評級照給。

目標價必須能由預測與評價兩段、淨負債與稀釋股數重算。論點檔填 `估法理由`、`內在價值`、`偏貴提醒價`、`低信心`、`資金成本`（不得為 null），SELL 填 `SELL第二理由`。BUY 也要列 downside；SELL 也要列能推翻空方的 bull case。

## 反幻覺與完成邊界

- 每個精確數字、日期、公司聲稱與法規效果都要有來源或公式；搜尋摘要、新聞轉述或模型記憶不算已驗證一級資料。
- 不把推論寫成管理層原話、目標寫成已達成、相關寫成因果；不補猜未揭露的分部、客戶、交易倍數、共識、目標價、WACC 或股數。
- 不混用基準日後資訊、不同股別、幣別、basic 與 diluted shares。
- 最新財報、價格、股數、淨負債或估值核心輸入缺失時標 `非決策就緒`，不給高精度評級；只能完成公司分析時明說缺口。

## 附錄：參考做法

| 情境 | 參考做法 |
|---|---|
| 獲利穩定 | 現行 forward P/E × 12 個月後 NTM EPS |
| 高成長未獲利 | 現行 EV／NTM 營收 × 12 個月後 NTM 營收，標低信心 |
| 週期股 | Bear 用 5–10 年正常化 EPS × 中週期本益比，P/B 歷史分位交叉檢查 |
| 銀行保險 | 現行 P/B × 12 個月後每股淨值，依 ROE 變化調整 |
| REIT／資源／集團 | NAV、P/AFFO、SOTP；內在價值用 NAV 或中週期現金流 |
| 成長變化調整倍數 | 同業迴歸斜率 × 成長率變化，R² 寫進報告；R² 低時維持現行倍數並標低信心 |
| 獲利暴增（下一年度 EPS 成長 > 50%） | Base 倍數取現行與歷史中位數的中點 |
| 歷史中位數口徑 | 實現前瞻本益比（當時股價 ÷ 之後實際四季 EPS），不與 trailing 混用 |
| 容忍倍數 | Low 1.05、Medium 1.10、High 1.15、Very High 1.25、Extreme 2.00（Morningstar 3／2 星交界，未逐一核對）；等級依近 12 個月年化波動，參考切線 20／30／40／55%（非規定） |
