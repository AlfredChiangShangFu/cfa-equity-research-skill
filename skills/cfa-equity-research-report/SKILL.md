# CFA 等級投資研究報告

## 核心契約

- 將「CFA 等級」解讀為基本面研究的深度、可稽核性與估值紀律，不得聲稱獲 CFA Institute 認證或背書。
- 即使使用者只給公司名或股票代號，也要自行完成上市地、股別、報告幣別、會計年度與研究基準日的辨識。只有在同名公司、雙重上市或股別會實質改變結果時才詢問。
- 預設以繁體中文交付一份完整 Markdown 報告。保持公司品質、股票估值與風險調整報酬三者分離。
- 對所有可能變動的價格、財報、指引、管理層、產品、競爭、法規與市場資料進行即時查證。若無法取得足夠的當期資料，不得把報告標示為可供決策。
- 產出研究報告，不自動延伸成個人化部位配置、交易指令、投資組合建議或其他產品。

## 必讀參考

開始研究前，完整讀取下列兩份檔案：

1. [report-blueprint.md](references/report-blueprint.md)：固定七章、各章必備表格與寫作形式。
2. [research-and-valuation-standards.md](references/research-and-valuation-standards.md)：來源層級、計算規則、產業估值選擇、評級與反幻覺門檻。

## 執行流程

### 1. 鎖定研究標的與截點

- 確認法定公司名、主要上市地、ticker、股別／ADR 比率、報告幣別、財務年度結束日與最新可交易收盤日。
- 把所有市場資料鎖在同一研究基準日。清楚區分「截至基準日已公開」與「基準日後發生」。
- 若使用者沒有指定同業，自行選擇 3–6 家商業模式、成長階段與資本結構最接近的公開同業；不可只挑能支持預設結論者。

### 2. 建立證據帳本

- 優先蒐集監管申報、交易所／監管機關資料、公司 IR、法說稿、財報簡報、正式產品／交易公告與同業各自的一級來源。
- 在分析過程中保留 `主張｜數值｜期間｜資料類型｜來源｜計算式／限制`。資料類型只可標為：已報告實績、管理層指引、外部預估、分析師假設、本研究計算或推論。
- 對每一個會改變投資結論的數字保留可追溯來源；同業資料使用相同或最近可比期間，並揭露 GAAP／non-GAAP、幣別與定義差異。

### 3. 重建經營與財務圖像

- 先理解產品、客戶、收費方式、分部、地理、通路、資本密集度與護城河，再選 KPI；不得把範例公司的 SaaS 指標硬套到其他產業。
- 在資料可得時重建至少 5 個完整年度與最近 5 季的關鍵財務，並核對損益表、資產負債表、現金流量表、股數與一次性調整。
- 將公司定義的 non-GAAP／FCF 指標與法定報表調節。所有代理指標、推算季度與自行重建數字都要緊接著註明公式與限制。
- 特別檢查 SBC、稀釋、租賃、可轉債、少數股權、資本化成本、營運資金、淨負債與表外承諾，避免只看企業層級成長而忽略每股價值。

### 4. 建模與形成可反駁的觀點

- 依 [research-and-valuation-standards.md](references/research-and-valuation-standards.md) 選擇適合產業的主估值法，至少再用一種方法交叉檢查。
- 建立內部一致的 Bear／Base／Bull 情境。每個情境同時調整營收／產量、利潤率、資本需求、折現率或倍數及稀釋，不可只改目標倍數。
- 在方法適用時提供 DCF、敏感度與 Reverse DCF；若不適用，改用經濟上等價的剩餘收益、NAV、DDM、P/AFFO 或中週期框架，並說明原因。
- 把目前股價隱含的成長、利潤率或報酬門檻與自身 Base／Bull 假設比較。評級必須由目前價格相對目標價及風險報酬推導，不得因公司故事優秀而自動給 BUY。

### 5. 按固定版型寫作

- 嚴格依 [report-blueprint.md](references/report-blueprint.md) 的七個 H2 標題與順序產出。
- 先在執行摘要給出研究基準日、評級、現價、12 個月與 36 個月目標價，再展開證據與模型。
- 將重要現況與 Base 情境數值加粗；表格下方立即放資料來源、計算方式與不可比限制。
- 使用描述性 Markdown 連結緊貼主張。不要輸出 `turn4view0`、`turn21search0`、`sandbox:/mnt/data/...` 等內部引用或失效附件路徑。
- 不設獨立的參考文獻章；來源應出現在相關段落或表格旁。圖表只有在能提高理解時才加入，並提供資料來源與單位。

### 6. 驗證後交付

- 逐項核對研究基準日、價格、股數、幣別、企業價值、目標價上／下行與最終評級彼此一致。
- 若報告已存成檔案，執行：

- 修正所有錯誤後再交付。若無法執行腳本，依相同清單人工檢查。
- 直接交付完整報告；不要用「以下是框架」或空白佔位符代替研究結果。資料缺失時寫 `未揭露`、`N/A` 或 `N/M`，並降低結論信心。

## 最低完成門檻

- 同一基準日的現價、市值／企業價值與帶日期的一級或權威市場來源。
- 最新年度／季度監管申報與公司財報資料，並與現金、債務、股數及關鍵 KPI 交叉核對。
- 至少一個主估值法、一個交叉檢查、Bear／Base／Bull、敏感度或等價壓力測試，以及 12／36 個月目標價。
- 對最重要的正面與負面論點，各提供可觀測證據、未來催化劑與可推翻條件。
- 每個重大事實與數值有鄰近來源；每個分析師假設與推論被明確標示。
- 明確回答：這是不是好公司、目前是不是好股票、什麼條件會證明評級錯誤。
