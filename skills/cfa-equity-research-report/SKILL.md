# CFA 式股權研究

## 不可降低的品質

- MD 是完整研究正文，深度只增不減；HTML 是從 MD 挑選的閱讀版，不顯示的內容用標記隱藏，不刪 MD。不能為節省 token、配合版型或通過腳本刪減論證、數字、來源或限制。
- 完整報告流程預設只載入本 skill 與 `ib-equity-research` HTML skill。非使用者指定，不載入其他股權研究 skill。
- 公司品質、股票估值與風險報酬分開判斷。
- 主代理負責商業邏輯、財務口徑、估值假設、反證、評級與最終主筆，模型沿用選定值（Codex 偏好 GPT-6 Sol），不自動切換，實際模型不同時如實說明。
- 預設分工，不是選項：取數、證據定位、同業比較、事件核實交 Claude `haiku`；論點檔、長逐字稿、`charts.json`、HTML 視覺檢查交 Claude `sonnet`；Codex 都交 GPT-6 Luna。主代理不讀截圖。由其他 session 啟動時，本 session 仍是第一層，照常派工。
- 最新核心資料不足須標示非決策就緒；不得以舊數據、代理摘要或漂亮排版補足證據缺口。
- 閱讀版排版：摘要快照先給足橫向欄寬，幣別與單位隨數值；半欄圖與解讀段落交錯、預設文字左圖右並頂部對齊，避免狹長側表與半頁空洞。具體驗收見 [交付程序](references/delivery.md) 的「圖文排版」。

## 研究流程

1. **界定標的與截點。** 確認上市地、股別／ADR、幣別、財年與最近完成收盤；資料各自保留期間及公布日。輸出路徑依專案 AGENTS.md，用派工日與執行系統代號。首次研究建立完整基線；更新研究先讀同系統既有模型與證據，檢查新申報、重編及事件後增量更新，仍交付完整八章 MD。
2. **取數與證據。** 開始取數前讀 [資料來源與更新](references/data-sources.md)、[研究與估值標準](references/research-and-valuation-standards.md) 及 [產業模板](references/industry/README.md)。台美股數據以 ToAlpha 優先；原始申報用於關鍵核驗、缺漏與衝突。先建共用資料，讀 [代理協定](references/subagent-research-protocol.md) 後把缺口平行派出。
3. **分析與建模。** 重建 5 個完整年度、最近 5 季及產業模板 KPI。以「經營驅動 → 收入／利潤 → 再投資與現金流 → 每股價值」形成可反駁論點；區分市場已反映的預期與自己的差異。遵循 standards 的估值口徑配對、主方法加交叉檢查、Bear／Base／Bull、敏感度、Reverse Valuation 與 12／36 個月目標價。籌碼與交易計畫依 [籌碼與事件交易標準](references/positioning-and-trade-plan.md) 對照同一投資論點。
4. **主筆與研究審閱。** 寫作前讀 [八章版型](references/report-blueprint.md)，寫法、章節結構與範例以它為準，保留完整深度。寫作時同時決定 `charts.json`、隱藏與附錄標記，並準備 config（頭部數值、Exhibit 標題、側欄清單），避免排版階段重新解讀研究。主代理讀回並核對因果鏈、最強反證、模型與評級、來源日期、股數與 EV、下一個月事件及交易條件；程式通過不等於研究合格。發現邏輯或數字問題可直接修正並重驗。
5. **交付。** 依 [MD → HTML 交付程序](references/delivery.md) 執行。先完成 MD 審閱與 strict 檢核，再接續排版、內容覆蓋檢查及視覺檢查；排版不得改寫 MD。使用者只要 MD 時省略 HTML；否則預設交付兩者，PDF 依要求。排版失敗明確區分「MD 已完成」與「HTML 未完成」。

## 最低完成門檻

- 帶日期與口徑的現價、市值／EV；最新財報、現金、債務、股數、指引及關鍵 KPI 可追溯。
- 主估值法、交叉檢查、三情境、敏感度、Reverse Valuation、12／36 個月目標價可由模型重算。
- 正反論點、催化劑與推翻條件有可觀測依據；事實、外部預估、假設與推論明確區分。
- 籌碼資料標明觀測日及公布延遲；技術價位可重算；未來 30 天催化劑、雙向風險與缺口明確列示。
- 八章 MD 明確回答好公司、好股票、目前交易行動及何時必須改變判斷；不得用摘要或框架替代完整研究。
