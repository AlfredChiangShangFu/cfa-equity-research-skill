# charts.json 規格

> 摘自原研究專案的 `docs/研究輸出格式.md` 第七節。文中的 ADR、issue 編號與 `研究報告/` 路徑是原專案的紀錄；沒有 thesis.json 時，同層一致性檢查不適用。

本節是**規範性**的。依 ADR 0010 第 2 點，報告的圖一律由資料檔產生，AI 不自行繪圖。資料檔放在 `研究報告/<標的>/<任務日期>/<AI>/charts.json`，與 `thesis.json` 同層。只有個股研究的新報告要求：同層有 `thesis.json` 且 `回填` 為 null 時，`build.js` 找不到 `charts.json` 會非零退出；產業研究、主題研究（`thesis-<代號>.json`）與 issue 03 回填的舊報告不要求。驗證：`node <ib-equity-research 安裝目錄>/charts.js validate <檔案>`。HTML 由 `ib-equity-research` 的 `build.js` 自動讀同層的 `charts.json`，繪圖程式在本 repo `tools/charts.js`（ADR 0011）。

**必有圖**：下表八種類型各至少一張，缺任一種 `validate` 與 `build.js` 都非零退出。產業層圖一律用 `柱線` 類型，張數與內容由產業模板（issue 21）決定。

| 類型 | 預設版面 | 畫什麼 |
|---|---|---|
| `估值區間` | 全寬 | 12M 與 36M 三情境目標價的 Bear 至 Bull 橫條（Base 為菱形），機率加權、評級價位線與基準日收盤價為直線；DCF、SOTP 等交叉檢查不入圖（issue 66 R114） |
| `日K` | 全寬 | 今年以來日 K，台式紅漲綠跌，均線，關鍵價位水平線；關鍵價位在畫面外時於邊緣畫箭頭並標數值 |
| `倍數河流` | 全寬 | 股價線疊在「倍數 × 每股指標」的色帶上 |
| `營收利益率` | 半欄 | 營收柱（預估期虛線上緣、淺色）＋營業利益率折線（右軸） |
| `現金流` | 半欄 | 營業現金流柱向上、資本支出柱向下、自由現金流折線 |
| `同業散佈` | 全寬 | 成長對倍數散佈點，本標的以深色標出，可帶區間線 |
| `敏感度` | 全寬 | 雙變數熱圖，主情境格深藍白字，不低於基準日收盤價的格加粗框 |
| `反向估值` | 全寬 | 每列一條啞鈴線：市場隱含要求對本報告 Base，另可列對照點；每列各自刻度 |
| `柱線` | 半欄 | 產業層通用：一到多組柱（左軸）加零到多條線（右軸），例如月營收與年增率、法人買賣超與融資餘額 |
| `組成` | 半欄 | 選用：單一期間的占比甜甜圈圖，例如產品群營收組成（issue 66） |
| `風險矩陣` | 全寬 | 選用：發生機率 × 衝擊的熱圖，風險章總覽（issue 66 R83） |

**數值慣例**：同論點檔。比率一律寫小數（19.1% 寫 0.191），`單位` 寫 `比率`；金額單位寫在 `單位` 字串（例如 `NT$ 百萬元`）；數字不得為 NaN 或 Infinity；未揭露的值寫 null，該點不繪製。

**以下範例為示意數字，不對應真實報告。**

```jsonc
{
  "版本": 1,
  "標的": { "代號": "2454.TW", "幣別": "TWD" },
  "研究基準日": "2026-09-18",     // 同層有 thesis.json 時必須與其一致
  "基準日收盤價": 1000,            // 同上
  "圖": [
    {
      "id": "valuation-range",     // 同檔唯一，英數與 -
      "類型": "估值區間",
      "標題": "估值區間：各方法 12M 每股價值",   // 成為 Exhibit 標題
      "章節": "估值",               // 插入的章：MD `##` 標題包含此字串的第一章，找不到時 build.js 非零退出
      "錨點": "### 目標價",          // 可省略；插在該章第一個包含此字串的區塊之後，省略時插在章末
      "版面": null,                 // 全寬 | 半欄 | null（用類型預設）
      "單位": "TWD",
      "口徑": "……",                 // 顯示在圖下來源註前段
      "來源": "……",                 // 顯示在圖下來源註
      "資料": { /* 依類型，見下 */ }
    }
  ]
}
```

**各類型的 `資料`**

- `估值區間`：`{ "列": [ { "名稱": "DCF Bear–Bull", "下緣": 600, "上緣": 1400, "中值": 900 } ], "參考線": [ { "名稱": "12M Base", "值": 870 } ] }`。`中值` 可為 null；基準日收盤價一律自動畫，不必列入參考線。
- `日K`：`{ "顯示起日": "2026-01-01", "均線": [20, 60], "K線": [ ["2026-01-02", 開, 高, 低, 收, 量] ], "關鍵價位": [ { "名稱": "12M 目標價", "價格": 1000, "右標": true } ], "價位區": [ { "名稱": "減碼區：1,100 以上", "下緣": 1100, "色調": "暖" } ], "分段": [ { "起日": "2026-01-02", "迄日": "2026-04-01", "標題": "等待訂單確認" } ], "事件": [ { "日期": "2026-07-31", "名稱": "Q2 法說" } ] }`。故事圖欄位都選用（issue 66 R31）：`事件` 畫成 K 棒旁的小框，箭頭指到當日 K 棒，框內第二行自動算「一週漲跌」（事件前一日收盤到含事件日在內第 5 根收盤，事件當天的跳空算進去；不足 5 根只寫日期）；`分段` 依時間排序不可重疊，K 棒區上方畫標題帶，漲跌自動算（段內首根開盤到末根收盤），標題 10 字內、寫有來源的原因，查不到原因只寫走勢；`價位區` 是水平底色帶，`下緣`／`上緣` 至少給一個，`色調` 只能是 暖／中性／冷（刻意不用紅綠，避免和紅漲綠跌混淆），區名寫在區塊左上角；`關鍵價位` 有任一筆 `右標: true` 時右側只標現價與這些價位，給了 `價位區` 而沒有右標時右側只標現價；這兩種情況下未標右標的價位連虛線都不畫（validate 會警告），價位應寫進區名。`K線` 第 6 欄成交量選用，整段都有值才畫成交量面板（台股以張顯示）；fill-prices 會自動帶入。`K線` 日期遞增，最後一筆必須是研究基準日；顯示起日之前要留足最長均線的天數，均線才會從第一天起有值。`K線` 用 `node <ib-equity-research 安裝目錄>/charts.js fill-prices <charts.json>` 從 Yahoo 自動填（未還原除息，與 `tools/tech.py` 同口徑），不手打；Yahoo 日線還沒有研究基準日那一根時工具非零退出，稍後重跑。
- `倍數河流`：`{ "倍數名稱": "Trailing P/E", "倍數帶": [15, 20, 25, 30], "每股指標": [ ["2023-03-31", 55.2] ], "價格": [ ["2023-01-06", 800] ] }`。`每股指標` 為階梯序列，每筆從該日起生效到下一筆；`倍數名稱` 要寫明 TTM 或 forward（CONTEXT.md 倍數口徑）。`價格` 為週收盤（每週最後一個不晚於研究基準日的交易日），填 `"auto"` 後跑 `fill-prices` 從第一筆每股指標日期起自動填；未填前 `validate` 會擋。
- `營收利益率`：`{ "期間": [ { "期間": "FY2025", "營收": 595966, "營業利益率": 0.1736, "預估": false } ] }`。
- `現金流`：`{ "期間": [ { "期間": "FY2025", "營業現金流": 162793, "資本支出": 25419, "自由現金流": 137373, "預估": false } ] }`。資本支出寫正數（流出）；自由現金流的定義寫在 `口徑`。
- `同業散佈`：`{ "x軸": "下一財年 EPS 成長", "x單位": "比率", "y軸": "Forward P/E（下一完整財年）", "y單位": "倍", "點": [ { "名稱": "聯發科", "x": 0.31, "y": 47.2, "y區間": [42.1, 52.3], "本標的": true } ] }`。`本標的` 恰好一點；`y區間` 可省略。
- `敏感度`：`{ "列名": "WACC", "欄名": "終端成長 g", "列": ["8.0%", "9.2%"], "欄": ["2.0%", "2.5%"], "值": [[2146, 2262], [1808, 1881]], "主情境": [1, 1] }`。`列`、`欄` 是顯示用標籤字串；`值` 為每股價值，維度必須等於列數 × 欄數；`主情境` 為 [列索引, 欄索引]（0 起），可為 null。
- `反向估值`：`{ "列": [ { "項目": "2027 資料中心營收", "單位": "US$bn", "市場隱含": 29.6, "隱含為下限": false, "本報告": 10.0, "對照": [ { "名稱": "管理層指引上緣", "值": 16 } ] } ] }`。`隱含為下限` 為 true 時標成「＞」（例如數學上不可達的毛利率）；無法寫成單一數值的組合條件留在正文，不入圖。
- `柱線`：`{ "期間": ["2026-07", "2026-08"], "預估": [false, false], "柱": [ { "名稱": "月營收", "值": [56300, 56360] } ], "線": [ { "名稱": "年增率", "值": [0.021, -0.034], "單位": "比率" } ], "左軸單位": "NT$ 百萬元" }`。各序列長度等於期間數；`預估`、`線` 可省略。選用 `"標值": true` 在柱頂標數值；期間 8 個以內時 X 軸每個類別都標，過寬自動斷兩行。類別名稱用讀者懂的詞（例：Base 假設、現價隱含），不用「本報告」「隱含」這類只有作者懂的簡稱。
- `組成`：`{ "期間": "2026Q2", "項目": [ { "名稱": "手機", "值": 0.41 }, { "名稱": "智慧裝置平台", "值": 0.53 } ] }`。至少兩項、值非負；合計與 1 差 5% 以上給警告，繪圖按合計正規化。
- `風險矩陣`：`{ "機率": ["低", "中", "高"], "衝擊": ["低", "中", "高"], "項目": [ { "名稱": "資料中心預期下修", "機率": "中", "衝擊": "高" } ] }`。兩個等級陣列由低到高、至少兩級；每項的機率與衝擊須在等級內。格子顏色依兩者合計，項目依序編號寫在格內。

**驗證規則**（`node <ib-equity-research 安裝目錄>/charts.js validate`）。錯誤使程式非零退出，警告只列印：

- 錯誤：`版本` 不是 1；缺必填欄位或型別不符；類型不在上表；八種必有類型缺任一種；`id` 重複或含英數與 `-` 以外的字元；日期格式非 `YYYY-MM-DD`；任一數字為 NaN 或 Infinity；同層 `thesis.json` 存在而研究基準日或基準日收盤價不一致；日K 最後一筆收盤、倍數河流最後一筆價格不等於基準日收盤價（相對誤差 0.0005 內視為相等）。
- 錯誤（依類型）：估值區間的下緣大於上緣或中值落在區間外；K線日期未遞增、高低價與開收不符（高 < max(開,收) 或低 > min(開,收)）、最後一筆不是研究基準日；倍數帶未遞增；倍數河流 `價格` 不是非空陣列或最後一筆晚於研究基準日；敏感度維度不符或主情境越界；同業散佈的本標的不是恰好一點；柱線序列長度與期間數不符。
- 警告：顯示起日之前的 K 棒少於最長均線天數；現金流的自由現金流與「營業現金流 − 資本支出」相差超過 1%；敏感度無主情境。

**版面**：全寬圖獨占一列；半欄圖在同一錨點連續兩張時並排，單張時與錨點段落並排（SKILL.md 第 3 節 Exhibit 版面分級）。第 1 章第一張表之前有圖時，該章不做正文與 Exhibit 1 並排。圖下來源註依序為 `單位`（值為 `混合` 時省略）、`口徑`、`來源`；折線遇 null 斷開。圖佔 Exhibit 編號，依出現順序與表格混合編號；`config.exhibits` 的鍵仍只數 MD 裡的表格與流程圖，所以既有 config 不必改。
